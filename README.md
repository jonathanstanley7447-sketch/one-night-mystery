# One-Night Mystery

A small public-beta experiment in personalized, browser-based mysteries.

## Play the demo

**The Missing Minute** is a short supernatural clockwork case: every clock in Bellwether House stops at 11:47, and one guest remembers the seven minutes that vanished.

The game is self-contained HTML/CSS/JavaScript. It requires no account, download, tracking, or personal information.

## Beta purpose

This repository tests whether people enjoy the format and whether there is interest in commissioned mysteries written around harmless details such as nicknames, places, objects, and inside jokes.

- Free demo: approximately 5–10 minutes
- Commission concept: a 15–20 minute private browser mystery
- Beta price target: $35
- No payment is currently collected

## Feedback

Use the repository's Issues tab for gameplay feedback and bug reports. Do not post names, private stories, email addresses, or other personal details in a public issue.

## Privacy

The demo has no analytics and transmits no player data. The commission-page prototype does not submit or store form contents.
